# ZaFe

本机使用的 macOS 菜单栏记录工具。纯文本、图片、文件引用与便签集中保存在本机。

## 构建与运行

需要完整 Xcode 26 或更新版本、Swift 6 和 macOS 26 或更新版本。本项目在 Apple 芯片 Mac 上开发，未验证其他系统和芯片。

```sh
bash scripts/build.sh
open dist/ZaFe.app
```

应用启动后只显示菜单栏图标。点击图标或按 **⌃⌥Space** 打开快捷面板；右键菜单可打开管理窗口、设置或退出。面板支持搜索、方向键选择和固定显示。单击剪贴板记录可在面板内查看详情，点击返回或按 Esc 回到列表，再按 Esc 可关闭面板。文本记录第二行显示最近一次复制时间。可点击记录右侧的复制按钮、在列表按回车（便签为查看与编辑），或使用详情页的复制按钮。复制后在目标软件按 **⌘V** 粘贴。

快捷面板可拖动顶部空白区域移动，并通过窗口边缘调整大小；位置和尺寸在退出重启后仍会保留。显示器变化时会将面板调整到可见区域内。按钮和列表项支持鼠标悬停高亮。

快捷面板使用原生液态玻璃，列表和便签编辑页均可透出后方窗口。点击顶部“外观”按钮可展开通透度滑块，范围 0–100%，默认 65%，实时生效并在重启后保留。100% 为原生 Clear 玻璃，仍有折射；0% 为实色背景。调节区展开时暂停列表的方向键和回车操作，Esc 优先收起调节区。系统开启“减少透明度”时使用实色背景并暂时禁用滑块，不覆盖已保存的数值。

文件可以拖入面板或管理窗口，也可从添加菜单选择文件、文件夹或剪贴板中的文件。引用不包含原件副本；删除引用不会删除原文件。点击快捷面板中的便签即可在面板内查看、编辑和删除，新建便签也在面板内完成；修改自动保存，点击返回或按 Esc 回到列表。便签不提供复制操作。管理窗口中单击记录可查看详情。快捷键可在设置中重新录制。

建议先将 `dist/ZaFe.app` 放到固定位置（例如个人“应用程序”目录），再开启登录启动。移动应用或重新签名后，可能需要重新开启此选项。本机构建使用临时签名，不需要开发者账号；系统拒绝登录启动注册时会在设置中显示错误，不会改装其他后台服务。

## 数据规则

- 普通剪贴板历史保留 30 天、最多 1000 条、最多 1000 MB；设置中可修改。相同内容更新现有记录，不重复添加。
- 单条文字或图片最多 20 MB。图片还须通过格式和像素尺寸校验；文件只存引用，不读取原文件内容。
- 便签、主动添加的文件和收藏长期保留。取消收藏的剪贴板条目重新参与历史清理。
- 主动保存的条目删除后可在“最近删除”中恢复，7 天后彻底清理。普通未收藏历史直接删除。
- 数据位于 `~/Library/Application Support/ZaFe/`。删除该目录会丢失记录；项目不提供导入导出或云同步，请使用自己的系统备份。

macOS 可能要求剪贴板或指定文件的访问授权。若系统处于“询问”或“拒绝”策略，自动读取会停止；在系统设置允许后台读取后，点击面板中的重试或开启记录。拒绝访问不会影响便签和其他已授权文件操作。不申请辅助功能、输入监控或完全磁盘访问。

复制下载、桌面或文稿目录里的文件时，系统可能请求该目录的访问权限。若之前拒绝过，请在“系统设置 → 隐私与安全性 → 文件与文件夹”中允许 ZaFe 访问，或通过“选择文件…”重新选择该文件。文件无法读取时会保留原剪贴板并显示提示。

首版不保留富文本排版，不过滤敏感复制内容，不加应用密码，也不包含 OCR、文件正文搜索或原文件移动和删除功能。

## 验证

```sh
CLANG_MODULE_CACHE_PATH="$PWD/.build/ModuleCache" \
SWIFTPM_MODULECACHE_OVERRIDE="$PWD/.build/ModuleCache" \
swift test --disable-sandbox --cache-path .build/cache
```

测试使用临时资料库和独立命名的剪贴板，不读取或覆盖日常剪贴板。系统授权、焦点返回、外观、文件预览及登录启动仍需在实际桌面会话中验收。登录启动开关不会在测试中操作。

开发时可以用 Xcode 打开 `Package.swift`；实际菜单栏和系统注册行为以构建出的 `.app` 为准。
